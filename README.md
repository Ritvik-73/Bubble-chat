# Bubble Chat

Real-time chat app with AI integration, built with React and Supabase.

## Stack

- React + Vite + Tailwind CSS
- Supabase — auth, database, realtime
- Google Gemini API — AI assistant
- Vercel — deployment

## Features

- Real-time messaging between users
- Private 1-on-1 chats + group chat
- Built-in AI assistant — type `@ai` in any room
- Online presence + typing indicators
- Email authentication
